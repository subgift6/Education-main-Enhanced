# RVG Gateway — مدیریت لینک‌ها و سابسکریپشن

پنل فارسی مبتنی بر FastAPI برای مدیریت لینک‌ها و گروه‌های سابسکریپشن، نمایش آمار، و ارائهٔ رابط مدیریتی راست‌چین. پروژه از VLESS over WebSocket و HTTP forwarding پشتیبانی می‌کند؛ پیش از استقرار، قوانین میزبان را دربارهٔ تونل‌زنی و پراکسی بررسی کنید.

## امکانات

- داشبورد فارسی RTL با طراحی واکنش‌گرا
- مدیریت لینک‌ها، محدودیت حجم و تاریخ انقضا
- ساخت گروه سابسکریپشن و صفحهٔ عمومی
- QR/کپی لینک‌ها و نمایش آمار
- ذخیره‌سازی state در فایل JSON (برای ماندگاری، Volume لازم است)
- پیکربندی امن‌تر برای ورود و endpoint پراکسی

## استقرار

1. ریپازیتوری را در GitHub قرار دهید.
2. در میزبان، متغیرهای `ADMIN_PASSWORD` و `SECRET_KEY` را تنظیم کنید. نمونهٔ نام متغیرها در `.env.example` آمده است؛ مقادیر واقعی را هرگز commit نکنید.
3. برای نگه‌داری داده‌ها بین restartها، یک Volume در مسیر `/data` متصل کنید.
4. از `Procfile` یا `railway.json` برای فرمان اجرای `uvicorn` استفاده می‌شود.
5. مسیر `/health` برای health check موجود است.

جزئیات بیشتر در [DEPLOYMENT.md](DEPLOYMENT.md) است.

## امنیت

- رمز پیش‌فرض قابل حدس در رابط ورود نمایش داده نمی‌شود.
- endpoint پراکسی عمومی بدون توکن صریحاً پیکربندی‌شده، درخواست را رد می‌کند.
- `SECRET_KEY` را پایدار نگه دارید؛ تغییر آن می‌تواند اعتبارسنجی رمز ذخیره‌شده را مختل کند.
- این پروژه برای پنهان‌کردن عملکرد از میزبان تغییر نام یا مبهم‌سازی نمی‌کند. سیاست میزبان را دربارهٔ VPN/proxy/tunnelling بررسی کنید.
